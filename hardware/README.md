# Case

This repository does not contain a 3D-printable case. The Helrig Box project has one for the same board (Waveshare ESP32-P4-NANO), in single-colour and multi-colour versions:

**https://github.com/maveric1977/helrig-box/tree/main/hardware/casing**

Their files are an adaptation, by the Helrig Box project, of the [Waveshare ESP32-P4-NANO case and board model](https://www.printables.com/model/1497431-waveshare-esp32-p4-nano-case-and-board-model) by MartinFaustMayer (@MartinFaustMa_212591) on Printables, under CC BY 4.0. Their lid has the Helrig symbol and wordmark debossed into it; if you want a plain lid, start from MartinFaustMayer's original on Printables. Credit and licence details are with their files.

We removed the files from this fork because the lid carries a brand that is not ours. A ToneStrand Box case, with our own mark, is not made yet.
