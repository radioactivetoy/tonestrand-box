      Password for the box's own network

      The box's own network (ToneStrand Box) is open until you set a password. It is what you join to edit with no Wi-Fi (direct mode: hold BOOT for 2 to 4 seconds). Anyone nearby can join an open network and the editing traffic is not encrypted.
